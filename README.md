# 与你相遇的夏天 · Meet You in Summer

一个简单的 ARG（另类实境游戏）解谜网页小游戏，采用终端（Terminal）风格的界面呈现。玩家需要在游戏内探索、分析，逐步解开隐藏在内容里的谜题。

## 如何游玩

直接双击打开 `index.html`，会自动跳转到游戏本体 `与你相遇的夏天.html`。游戏为单文件 HTML，无需安装任何依赖，离线可直接运行。

也可以直接在线游玩（无需下载，打开浏览器即可）：

- 在线地址：https://microovo.github.io/simple-arg-game/

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 启动器页面，跳转到游戏本体 |
| `与你相遇的夏天.html` | 游戏本体，包含全部谜题与逻辑 |
| `promo_2006.png` | 宣传图，其中以 LSB 隐写藏有谜题线索 |

## 提示

宣传图里藏有线索，可以尝试分析它的像素位（LSB 隐写）。祝通关愉快。

> 本仓库仅收录游戏本体资源，谜题答案、设计文档与宣传图源文件未随仓库公开。
